# 設定說明與測試清單

## 響鈴行為（App → 進階設定與除錯）

| 設定 | 作用 | 建議值 |
|---|---|---|
| **App 警報聲** | 時間到後 App 自己循環播「鬧鐘聲音」選的音檔，同時每 0.9 秒震動一次，實體按鍵停不掉。只在掃描緩衝時暫停，掃到 QR 才停 | 開 |
| **鬧鐘聲音**（主畫面也有入口） | 系統鬧鐘和 App 警報聲共用。內建 4 種（極限尖叫、隨機轟炸、防空警報、舊版警笛）、自己匯入（檔案 App 或音檔網址，轉成 44.1 kHz 單聲道、截 29 秒，可選「加強音量」壓縮）、系統預設鈴聲（App 警報聲仍用極限尖叫）。每個都能試聽 10 秒，上膛中鎖住 | 極限尖叫（如果測出系統鬧鐘沒聲音就改系統預設） |
| **按停止後 N 秒重響** | 按 AlarmKit 的「停止」後，N 秒再響一顆；關掉相機沒掃到也是 N 秒後恢復 | 1 秒 |
| **響 N 秒沒解除就換新的**（刷新） | AlarmKit 鬧鐘響了 N 秒（包括被按鍵靜音）就取消、1 秒後換新的一顆。App 每 2 秒檢查，實際是 N～N+2 秒。太短會變成響停響停，0 = 關閉 | 5 秒 |
| **掃描緩衝** | 按「掃描」打開相機時，所有聲音暫停 N 秒。應該先走到 QR 那裡再按掃描，所以只要涵蓋開相機到掃到的時間 | 20 秒 |
| **保底鬧鐘每 N 秒、N 顆** | 事先多排幾顆 AlarmKit 鬧鐘。**疊在一起會讓聲音消失**，而且 App 活著時每次刷新都會重排，所以沒有用處 | 1 顆（等於關閉） |
| **按停止會重排** | 按停止後要不要重響 | 開 |
| **stopIntent 內呼叫 stop()** | 實驗用，實測沒有影響 | 開 |

## 睡前提醒（主畫面「設定」卡片）

| 設定 | 作用 | 建議值 |
|---|---|---|
| **睡前提醒** | 每天這個時間如果還沒上膛，跳 Time Sensitive 通知「今晚還沒上膛」。一次排 7 天，每次打開 App 會補排；已上膛就不會跳今晚那則 | 開 |
| **提醒時間** | 通知時間 | 23:30 |

## 天氣（主畫面「設定」卡片）

| 設定 | 作用 | 建議值 |
|---|---|---|
| **天氣位置** | 按一下用目前位置設定（只抓一次，要允許定位「使用 App 期間」）。在家裡設定一次就好 | 家裡 |
| **起床語音播報** | 解鎖成功約 1 秒後用內建中文（台灣）語音唸短天氣：現在溫度、最高溫、穿什麼、要不要帶傘（約 5 秒）。天氣卡的喇叭可再聽一次。靜音鍵開著也會唸 | 開 |
| **氣象署授權碼** | 中央氣象署開放資料的 API 授權碼（opendata.cwa.gov.tw 會員資訊 → 取得授權碼）。填了就用氣象署鄉鎮預報，沒填或失敗用 Open-Meteo。只存在手機 | 填 |
| **穿衣體質** | 怕冷／普通／怕熱：體感溫度 −2／0／+2 後再決定穿什麼 | 怕熱 |

建議考慮的時段是「現在到晚上 10 點」。穿衣表（修正後體感）：外套看最低溫 ≥ 24 不用、20～23 薄外套、16～19 外套、12～15 厚外套、< 12 羽絨衣；內層看最高溫 ≥ 24 短袖、18～23 長袖、12～17 長袖＋內搭。

## 捷徑與 Siri

- 捷徑 App 裡的「上膛起床鬧鐘」（參數：時、分），或對 Siri 說「用起床設鬧鐘」「起床上膛」。算時間的規則跟 App 的滾輪一樣（下一個符合的時刻）。
- **已上膛或響鈴中會被拒絕**（「鬧鐘進行中，不能改時間」）。捷徑、Siri、小工具、控制中心都沒有停止或延後的功能。

## 螢幕

| 設定 | 作用 | 建議值 |
|---|---|---|
| **上膛後保持螢幕亮著** | 開：螢幕不會自動熄滅（夜間畫面全黑）。關：跟隨系統或引導模式的「螢幕自動鎖定」 | 開（等自動鎖定測試結果） |

## 系統設定（手機的設定 App）

| 位置 | 設定 |
|---|---|
| 設定 > 輔助使用 > 引導使用模式 | 打開；密碼設成 App 產生的 4 位數；**Face ID 關掉**；螢幕自動鎖定先用「預設值」 |
| 引導模式啟動時的「選項」 | 關掉「側邊按鈕」「音量按鈕」，「觸控」保持開 |
| 設定 > 聲音與觸覺 | 鈴聲與提示聲拉到最大；「使用按鈕調整」關閉 |
| 設定 > 一般 > 軟體更新 > 自動更新 | 關閉（避免半夜重開機） |

## 測試清單

**一律在鎖屏或引導使用模式下測試。** QR 放手邊。

### 基本（不開引導模式、鎖屏）
- [ ] 進階 → 2 分鐘後響 → 鎖屏：時間到有 AlarmKit 鬧鐘和刺耳的 App 警報聲
- [ ] 按音量鍵：AlarmKit 的聲音停，App 警報聲繼續；約 5～7 秒後 AlarmKit 換新的、恢復聲音
- [ ] 按「停止」：約 1 秒後重響
- [ ] 按「去掃描」→ 解鎖：相機馬上出來、聲音暫停
- [ ] 掃 QR：全部停止，等 30 秒不再響

### 引導使用模式
- [ ] 2 分鐘後響 → 連按三下側鍵 → 開始
- [ ] 啟動當下音量有沒有突然變小
- [ ] 時間到：黑畫面變紅色響鈴畫面，有警報聲
- [ ] 音量鍵、側鍵都沒作用
- [ ] 按「掃描」掃 QR：全部停止，畫面顯示 4 位數密碼
- [ ] 連按三下側鍵輸入密碼 → 結束

### 螢幕自動鎖定（待測）
- [ ] 進階 → 「上膛後保持螢幕亮著」關掉；引導模式的「螢幕自動鎖定」設 1 分鐘
- [ ] 2 分鐘後響 → 開始引導模式 → 什麼都不碰
- [ ] 螢幕是否在 1 分鐘後自己關掉
- [ ] 響的時候按鍵是否仍然沒作用（最關鍵）
- [ ] 點螢幕喚醒後是否仍在引導模式、看到響鈴畫面

### 鬧鐘聲音（待測）
- [ ] 主畫面「鬧鐘聲音」→ 每個內建音按 ▶︎ 能試聽，再按一次停；靜音鍵開著也聽得到
- [ ] 選「極限尖叫」→ 2 分鐘後響 → 鎖屏：**系統鬧鐘**是不是這個聲音（不是 iOS 預設鈴聲）
- [ ] App 警報聲也是同一個聲音；響的時候手機一直震動
- [ ] 從檔案匯入一首 mp3（Safari 下載的在「檔案 → 下載項目」）→ 試聽 → 2 分鐘後響：**系統鬧鐘**能不能播匯入的聲音（放在 Library/Sounds，文件說可以，論壇有人說會退回預設）
- [ ] 貼音檔網址下載；貼 YouTube／網頁網址應該顯示錯誤
- [ ] 左滑改名、刪除；刪掉正在用的會自動換回極限尖叫
- [ ] 上膛中進不去選（灰掉）

### 小工具、睡眠、提醒、捷徑（分支 `claude/widgets-sleep`）
- [ ] 加入小工具：桌面小、中；鎖定畫面矩形、圓形、單行
- [ ] 上膛 → 小工具顯示時間、倒數、📍地點；到時間自己變橘色、已響時間在跳
- [ ] 響鈴時鎖屏的即時動態、動態島：黑橘、「去{地點}掃碼」、已響時間
- [ ] 控制中心加「起床」按鈕：按了只打開 App
- [ ] 上膛後分頁列消失，點下方不會跑去睡眠頁
- [ ] 睡前提醒設成 2 分鐘後、不上膛 → 有通知；上膛後再設一次 → 今晚不會跳
- [ ] Siri「用起床設鬧鐘」→ 問時、分 → 上膛成功
- [ ] **響鈴中或已上膛時對 Siri 說同一句 → 被拒絕「鬧鐘進行中，不能改時間」，鬧鐘時間不變**

測完到「進階 → 記錄」，右上角分享 `poc.log`。

### 天氣（1.0.<下一版>）
- [ ] 在家按「天氣位置」→ 允許定位 → 主畫面出現天氣卡（溫度、體感、到 22 點的範圍、穿什麼、要不要帶傘）
- [ ] 下拉重新整理：「更新於」時間改變
- [ ] 上膛後天氣卡不見；感應 NFC 解除後，密碼卡下面出現天氣卡
- [ ] 記錄裡有「🌤 天氣更新（上膛）」「（鬧鐘前）」「（起床）」
- [ ] 填氣象署授權碼後下拉重新整理：天氣卡右上寫「中央氣象署」，天氣位置那列顯示縣市＋鄉鎮區；記錄有「📍 氣象署鄉鎮：…」
- [ ] 引導使用模式下解鎖成功：約 1 秒後聽到「早安，現在…度」；記錄有「🗣 語音播報」
- [ ] 授權碼故意打錯：記錄出現「氣象署失敗…授權碼不對（401）」，天氣卡改寫「Open-Meteo」
- [ ] 跟手機內建天氣比對溫度和降雨機率，覺得穿衣建議太冷或太熱就回報

### NFC（待測）
- [ ] 進階 → 登錄新的 NFC 標籤 → 清單出現 UID
- [ ] 掃描 NFC 驗證：記錄出現「正確（目前未上膛，只是測試）」；用悠遊卡測「沒有登錄過」
- [ ] 解鎖方式選 NFC → **不開引導模式**、鎖屏，2 分鐘後響：響鈴畫面寫「感應 NFC 卡片」，按下有 NFC 視窗，感應後解除
- [ ] **開引導模式**再測一次：NFC 視窗會不會出現；不出現的話紅字顯示什麼、「改用 QR Code」能不能解除
