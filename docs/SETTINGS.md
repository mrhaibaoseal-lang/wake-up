# 設定說明與測試清單

## 響鈴行為（App → 進階設定與除錯）

| 設定 | 作用 | 建議值 |
|---|---|---|
| **App 警報聲** | 時間到後 App 自己循環播刺耳警報音，實體按鍵停不掉。只在掃描緩衝時暫停，掃到 QR 才停 | 開 |
| **系統鬧鐘用刺耳警報音** | AlarmKit 鬧鐘改用 `wake_alarm.wav`；關掉則用系統預設鈴聲 | 開（如果測出系統鬧鐘沒聲音就關掉） |
| **按停止後 N 秒重響** | 按 AlarmKit 的「停止」後，N 秒再響一顆；關掉相機沒掃到也是 N 秒後恢復 | 1 秒 |
| **響 N 秒沒解除就換新的**（刷新） | AlarmKit 鬧鐘響了 N 秒（包括被按鍵靜音）就取消、1 秒後換新的一顆。App 每 2 秒檢查，實際是 N～N+2 秒。太短會變成響停響停，0 = 關閉 | 5 秒 |
| **掃描緩衝** | 按「掃描」打開相機時，所有聲音暫停 N 秒。應該先走到 QR 那裡再按掃描，所以只要涵蓋開相機到掃到的時間 | 20 秒 |
| **保底鬧鐘每 N 秒、N 顆** | 事先多排幾顆 AlarmKit 鬧鐘。**疊在一起會讓聲音消失**，而且 App 活著時每次刷新都會重排，所以沒有用處 | 1 顆（等於關閉） |
| **按停止會重排** | 按停止後要不要重響 | 開 |
| **stopIntent 內呼叫 stop()** | 實驗用，實測沒有影響 | 開 |

## 螢幕

| 設定 | 作用 | 建議值 |
|---|---|---|
| **上膛後保持螢幕亮著** | 開：螢幕不會自動熄滅（夜間畫面全黑）。關：跟隨系統或引導模式的「螢幕自動鎖定」 | 開（等自動鎖定測試結果） |

## 系統設定（手機的設定 App）

| 位置 | 設定 |
|---|---|
| 設定 > 輔助使用 > 引導使用模式 | 打開；密碼設成 App 產生的 4 位數；**Face ID 關掉**；螢幕自動鎖定先用「預設值」 |
| 引導模式啟動時的「選項」 | 關掉「側邊按鈕」「音量按鈕」，「觸控」保持開 |
| 設定 > 聲音與觸覺 | 鈴聲與提示聲拉到最大；「使用按鈕調整」關閉 |
| 設定 > 一般 > 軟體更新 > 自動更新 | 關閉（避免半夜重開機） |

## 測試清單

**一律在鎖屏或引導使用模式下測試。** QR 放手邊。

### 基本（不開引導模式、鎖屏）
- [ ] 進階 → 2 分鐘後響 → 鎖屏：時間到有 AlarmKit 鬧鐘和刺耳的 App 警報聲
- [ ] 按音量鍵：AlarmKit 的聲音停，App 警報聲繼續；約 5～7 秒後 AlarmKit 換新的、恢復聲音
- [ ] 按「停止」：約 1 秒後重響
- [ ] 按「去掃描」→ 解鎖：相機馬上出來、聲音暫停
- [ ] 掃 QR：全部停止，等 30 秒不再響

### 引導使用模式
- [ ] 2 分鐘後響 → 連按三下側鍵 → 開始
- [ ] 啟動當下音量有沒有突然變小
- [ ] 時間到：黑畫面變紅色響鈴畫面，有警報聲
- [ ] 音量鍵、側鍵都沒作用
- [ ] 按「掃描」掃 QR：全部停止，畫面顯示 4 位數密碼
- [ ] 連按三下側鍵輸入密碼 → 結束

### 螢幕自動鎖定（待測）
- [ ] 進階 → 「上膛後保持螢幕亮著」關掉；引導模式的「螢幕自動鎖定」設 1 分鐘
- [ ] 2 分鐘後響 → 開始引導模式 → 什麼都不碰
- [ ] 螢幕是否在 1 分鐘後自己關掉
- [ ] 響的時候按鍵是否仍然沒作用（最關鍵）
- [ ] 點螢幕喚醒後是否仍在引導模式、看到響鈴畫面

### 自訂聲音（待測）
- [ ] 系統鬧鐘是不是刺耳警報音，而不是原本的鈴聲
- [ ] 夠不夠可怕、會不會太小聲

測完到「進階 → 記錄」，右上角分享 `poc.log`。
